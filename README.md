# ☕ Coffee Shop POS & Inventory Management System
> ระบบขายหน้าร้าน (POS) และบริหารจัดการสต๊อกวัตถุดิบตามสูตรเครื่องดื่ม สำหรับร้านกาแฟ ใช้งานได้จริง ครบวงจร 100%

---

## 🌟 จุดเด่นและฟังก์ชันหลักของระบบ (Features)

1. **POS ขายสินค้าหน้าร้าน (Point of Sale)**
   - แคตตาล็อกสินค้าพร้อมแยกหมวดหมู่ (กาแฟ, ชา, นม, โซดา, เบเกอรี่)
   - หน้าต่างปรับแต่งเครื่องดื่ม (ร้อน / เย็น / ปั่น, ระดับความหวาน 0%-100%, ตัวเลือกเพิ่มช็อตกาแฟ, วิปครีม, ไซรัป)
   - คำนวณราคาสินค้า ส่วนลดรายการ ส่วนลดทั้งบิล และยอดสุทธิโดยอัตโนมัติ
   - ชำระเงินสดพร้อมคำนวณเงินทอน (ปุ่มลัดธนบัตร ฿100, ฿500, ฿1,000, พอดีบิล)
   - ชำระผ่าน QR PromptPay และบัตรเครดิต
   - บันทึกการขายและตัดสต๊อกใน **Database Transaction เดียวกัน** ป้องกันข้อมูลไม่ตรงกัน
   - ป้องกันการส่งคำขอชำระเงินซ้ำด้วย **Idempotency Key**
   - พิมพ์ใบเสร็จรับเงิน (Thermal Receipt 58 มม. และ 80 มม.)

2. **ระบบสูตรเครื่องดื่ม (Recipe / Bill of Materials - BOM)**
   - ผูกเมนูเครื่องดื่มและตัวเลือก (เช่น เพิ่มช็อต) เข้ากับวัตถุดิบจริง
   - เมื่อมีการขาย ตัดสต๊อกวัตถุดิบและบรรจุภัณฑ์ (เมล็ดกาแฟ, นมสด, น้ำแข็ง, แก้ว, ฝา, หลอด) อัตโนมัติคูณตามจำนวนแก้ว
   - คำนวณต้นทุนวัตถุดิบต่อแก้ว (Cost per Cup) และกำไรขั้นต้น (Gross Profit Margin %) แบบเรียลไทม์

3. **ระบบคลังวัตถุดิบและสต๊อก (Inventory Management)**
   - ติดตามสต๊อกคงเหลือจริง จุดสั่งซื้อขั้นต่ำ และมูลค่าสินค้าคงคลังรวม
   - บันทึกของเสีย ชำรุด (Waste) และเบิกใช้ภายในร้าน (Usage) พร้อมเหตุผล
   - บันทึกประวัติการเคลื่อนไหวสต๊อกทั้งหมด (**Inventory Movements Audit Trail**)
   - นโยบายความปลอดภัย: ป้องกันการขายจนสต๊อกติดลบ (เปิด/ปิดได้ในการตั้งค่า)

4. **รับสินค้าเข้าสต๊อก (Purchase Receipts)**
   - สร้างเอกสารรับสินค้าเข้าจากซัพพลายเออร์ เพิ่มสต๊อกจริงพร้อมคำนวณต้นทุนถัวเฉลี่ยถ่วงน้ำหนัก (Weighted Average Cost)
   - ป้องกันการยืนยันซ้ำ และสามารถยกเลิกเอกสารรับพร้อมปรับสต๊อกคืนได้

5. **แดชบอร์ดและรายงานวิเคราะห์ (Dashboard & Analytics)**
   - สรุปยอดขายวันนี้, จำนวนบิล, แก้วที่ขายได้, ยอดเฉลี่ยต่อบิล, ต้นทุนวัตถุดิบขาย (COGS), กำไรขั้นต้น
   - แจ้งเตือนวัตถุดิบที่ต่ำกว่าจุดสั่งซื้อขั้นต่ำ
   - กราฟยอดขายรายชั่วโมงและอันดับเมนูขายดี
   - รายงานยอดขายรายวัน, ยอดขายแยกตามเมนู, การใช้วัตถุดิบจริง, และงบกำไรขาดทุนเบื้องต้น (P&L)
   - **ส่งออกไฟล์ CSV ภาษาไทย (UTF-8 BOM)** เปิดใน Microsoft Excel ได้ทันทีโดยสระไม่เพี้ยน

6. **สำรองและกู้คืนฐานข้อมูล (Backup & Restore)**
   - สำรองฐานข้อมูลแบบ Snapshot ผ่านคำสั่ง `VACUUM INTO` ของ SQLite โดยไม่ต้องหยุดระบบ
   - ดาวน์โหลดไฟล์ `.db` เก็บรักษาหรือใช้ย้ายเครื่องคอมพิวเตอร์
   - ระบบกู้คืนตรวจสอบความสมบูรณ์ของไฟล์ (`PRAGMA integrity_check`) และสร้าง **Safety Backup** อัตโนมัติก่อนเขียนทับ

7. **ระบบผู้ใช้งานและสิทธิ์ (Multi-Role Authentication)**
   - สลับพนักงานแคชเชียร์ประจำเครื่องได้อย่างรวดเร็ว
   - บทบาท: เจ้าของร้าน (Owner), พนักงานขาย (Cashier), ผู้จัดการสต๊อก (Stock Manager)
   - เข้ารหัสผ่านด้วย `bcrypt`

## 🛠️ สถาปัตยกรรมและเทคโนโลยีที่ใช้ (Tech Stack)

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons
- **Backend**: Node.js v24, Express, TypeScript, Zod, Bcrypt, JWT
- **Database**: SQLite (ขับเคลื่อนด้วย Built-in `node:sqlite` DatabaseSync ประสิทธิภาพสูง ไม่ต้องติดตั้งโปรแกรมฐานข้อมูลแยก ป้องกันความขัดแย้งของ C++ compiler)
- **Data Safety**: Atomic Transactions (`BEGIN IMMEDIATE` / `COMMIT` / `ROLLBACK`), WAL Mode, Foreign Keys Enforced
- **Testing**: Vitest Automated Testing Suite (ทดสอบการขาย, การตัดสต๊อก, การคำนวณเงินทอน, การยกเลิกบิล, และการสำรองข้อมูล)

## 🚀 คำสั่งเริ่มต้นใช้งาน (Getting Started)

### 1. ติดตั้ง Dependencies ทั้งหมด
```bash
npm run install:all
```

### 2. สร้างฐานข้อมูลและลงข้อมูลตัวอย่างภาษาไทย (Seeding)
```bash
npm run seed
```

### 3. รันโปรเจกต์ในโหมดพัฒนา (Development Mode)
คำสั่งนี้จะเปิดทั้ง Backend API (Port 5000) และ Frontend Vite (Port 3000):
```bash
npm run dev
```
เปิดเบราว์เซอร์เข้าใช้งานที่: **`http://localhost:3000`**

### 4. รันคำสั่งทดสอบระบบอัตโนมัติ (Automated Tests)
```bash
npm run test
```

### 5. บิลด์สำหรับใช้งานจริง (Production Build)
```bash
npm run build
npm start
```
ระบบจะเปิดบริการ Backend และ Client ผ่าน Single Port ที่: **`http://localhost:5000`**

| ชื่อผู้ใช้ (Username) | รหัสผ่าน (Password) | บทบาท (Role) | สิทธิ์การใช้งาน |
|---|---|---|---|
| `owner` | `password123` | **เจ้าของร้าน (Owner)** | เข้าถึงทุกเมนู จัดการสต๊อก ดูรายงาน ตั้งค่า และสำรองข้อมูล |

## 🔒 ความปลอดภัยและความน่าเชื่อถือของข้อมูล

1. **การคำนวณราคาฝั่งเซิร์ฟเวอร์**: ป้องกันไม่ให้ฝั่ง Client ดัดแปลงราคาสินค้าหรือราคาตัวเลือก
2. **การตัดสต๊อกแบบอะตอมมิก (ACID)**: หากเกิดข้อผิดพลาดขั้นตอนใดขั้นตอนหนึ่งขณะขาย ข้อมูลทั้งหมดจะถูก Rollback ทันที ทำให้ไม่เกิดกรณีขายสำเร็จแต่สต๊อกไม่ตัด
3. **การป้องกันการกดซ้ำ**: ใช้ Idempotency Key ป้องกันการสร้างบิลซ้ำจากการกดปุ่มชำระเงินรัว
4. **ความถูกต้องของประวัติย้อนหลัง**: เมื่อมีการขาย ระบบจะเก็บ Snapshot ชื่อสินค้า ราคา และตัวเลือก ณ ขณะขายไว้ในตาราง `sale_items` เพื่อให้การแก้ไขราคาสินค้าในปัจจุบันไม่กระทบกับบิลย้อนหลัง
5. **การกู้คืนข้อมูลที่มีระบบนิรภัย**: ระบบจะสร้าง Snapshot สำรองข้อมูลปัจจุบันให้อัตโนมัติทุกครั้งก่อนเริ่มดำเนินการ Restore
